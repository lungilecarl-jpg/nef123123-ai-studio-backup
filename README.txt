# NEF123123 Website

A responsive, single-page editorial website for NEF123123 — Navigant Economic Freedom.

## Files
- `index.html` — website structure and page content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, date/year and newsletter demo interaction

## Preview locally
Open `index.html` in a modern browser. Internet access is needed for the remote editorial photographs and Google Fonts. The site itself is static and does not require a build step.

## Publish
Upload `index.html`, `styles.css`, and `script.js` together into the web root (`public_html` or equivalent) of a static web host. Keep all three files in the same folder. The homepage file must be named `index.html`.

This package is a standalone static website. It does not automatically connect to GoDaddy Airo, Google AI Studio, GitHub, a CMS, or your domain. Your domain's DNS/hosting must point to the host where these files are uploaded.

## Before launch
1. Confirm the official contact email in the footer (`info@nef123123.co.za` is a suggested placeholder).
2. Connect the newsletter form to an email marketing service or backend. The current form displays a confirmation but does not store addresses.
3. Add your official social-media links and affiliate logos.
4. Replace the sample editorial feature copy and images with approved NEF articles and photography.
5. The descriptions for pillars 03–07 are proposed editorial wording. Confirm or replace them with the movement's formally adopted wording.
6. Add your Google AdSense publisher code and a real `/ads.txt` file only after receiving the exact publisher record from AdSense.
7. Add a privacy policy and cookie notice if you collect personal information or use advertising/analytics services.

## Design
The layout takes inspiration from the content hierarchy of large news portals (lead story, topic sections, side rail, article cards and navigation) while using original NEF123123 branding and styling.
